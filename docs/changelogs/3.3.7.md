# v3.3.7 - 2026-09-26

## Changes
- WoW Forever beta (project Camelot, build 69913, interface 16001) is fully supported alongside Classic Era, TBC Classic, Mists Classic, and Retail.
- Fixed: disabling the addon now re-shows debuffs on already-visible nameplates immediately (in-place restore); no full nameplate rebuild flash.
- Fixed: hide no longer clears the Blizzard BuffFrame's anchor points; restore is a pure inverse of hide. Nameplate unit resolution now falls back to namePlateUnitToken when needed.

## Beta cycle this release grew out of
- 3.3.7-beta.1: maintenance beta verified against RGX-Framework 2.7.8.
- 3.3.7-beta.2: re-show fix via forced nameplate rebuild after restore.
- 3.3.7-beta.3: in-place restore; the automatic rebuild was removed after testing showed it visibly blinked every enemy plate.
