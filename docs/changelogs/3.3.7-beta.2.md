# v3.3.7-beta.2 - 2026-09-25

## Changes
- Fixed: disabling the addon no longer re-hides debuffs it had removed
  earlier. Visible nameplates now rebuild via a forced nameplate refresh
  after restore, so debuffs re-show immediately on the WoW Forever beta
  client (and any other flavor that only re-evaluates aura widgets when
  the plate is recreated).
- Hide no longer clears the Blizzard BuffFrame's anchor points; restore
  is now a pure inverse of hide.
- Nameplate unit resolution falls back to `namePlateUnitToken` when the
  UnitFrame does not expose a unit.
