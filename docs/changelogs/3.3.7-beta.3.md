# v3.3.7-beta.3 - 2026-09-25

## Changes
- Disabling the addon no longer forces a full nameplate rebuild, which
  visibly blinked every enemy nameplate for ~0.3s. Restore now happens
  in place (pure inverse of hide), which works because hide no longer
  clears the Blizzard BuffFrame's anchor points.
- The forced rebuild remains available as a manual fallback via
  `/rnd test`.
